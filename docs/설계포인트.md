## 포인트 충전과 환전: 동시성, 멱등성, 보상 트랜잭션

- 목표: 실제 계좌 송금(SSAFY 금융망)과 포인트 원장 간 정합성 보장
- 환율 단일 기준
  - `10원 = 1P` 환산은 `PointExchangePolicy` 한 곳에서만 수행
  - 10원 단위가 아닌 금액은 요청 단계에서 거부 → 버림으로 인한 잔돈 유실 방지
- 동시성 제어
  - 잔액 변경 전 지갑 행 비관적 락(`SELECT ... FOR UPDATE`)
  - 환전 승인, 거절, 취소 시 요청 행도 잠금 → 동일 요청의 이중 처리 방지
- 멱등성 보장
  - 포인트 거래에 멱등키 적용, `(child_id, idempotency_key)` UNIQUE 제약
  - 이미 처리된 충전 요청 재수신 시 송금 생략 → 이중 출금 방지
- 충전 (원 → 포인트)
  - 검증(금액, 잔액 상한, 멱등성) 통과 후 포인트 발행 → 송금 순서
  - 발행과 송금을 단일 트랜잭션으로 처리 → 송금 실패, 금액 불일치 시 발행까지 롤백
- 환전 (포인트 → 원) — 보상 트랜잭션
  - 요청 시 포인트 선차감, 부모 승인 시 송금 (서로 다른 트랜잭션)
  - 문제: 차감은 이미 커밋된 상태 → 송금 실패 시 롤백으로 복구 불가
  - 해결: 송금 실패 시 예외 대신 **같은 트랜잭션 내 포인트 환급(보상) + 요청 `FAILED` 처리**
  - 부모 거절, 아이 취소도 동일한 환급 흐름 적용
  - 환급 거래에 파생 멱등키(`{key}:refund` 등) 부여 → 중복 환급 방지

## RabbitMQ 기반 비동기 처리 (Spring ↔ AI 서버)

- 목표: 느리고 실패 가능성이 있는 LLM 호출을 사용자 요청 흐름에서 분리
- 역할 분리
  - LLM 로직(투자 뉴스, 가격 갱신, 금융 퀴즈, 상점 가격 책정, 할 일 보상 책정)은 FastAPI AI 서버 담당
- 즉시 응답 + 비동기 산정
  - 상점 상품, 할 일 등록 시 가격, 보상 칸을 비운 채 저장 후 즉시 응답
  - RabbitMQ로 산정 요청 발행 → AI 서버가 구독 후 가격, 보상 채움
- 커밋 후 발행
  - `@TransactionalEventListener(AFTER_COMMIT)`에서 발행
  - 등록 트랜잭션 롤백 시 메시지 미발행 → 존재하지 않는 행 처리 방지
- 최신 값 기준 산정
  - AI 서버는 메시지 값 대신 ID로 DB 재조회
  - 발행~처리 사이의 용돈, 난이도 변경도 반영
- 실패 처리
  - DLQ 미사용 → 무조건 requeue 시 영구 실패 무한 반복 위험
  - 기본 ACK, 일시적 실패(DB 연결 끊김 등)만 1회 재시도
  - 이미 산정된 행은 건너뜀 → 중복 메시지에도 안전
- 정기 생성 작업
  - 뉴스, 퀴즈는 Spring 크론이 내부 API(`INTERNAL_TOKEN` 인증)로 AI 서버 호출
  - AI 작업 전부 멱등 → 재호출 안전

## 정기 작업 (KST)

| 시각 | 작업 |
| --- | --- |
| 00:00 | 반복 할 일 기간 갱신 (매일 / 매주 월요일 / 매월 1일) |
| 00:05 | 오늘의 투자 뉴스 생성, 가족별 종목 가격 갱신 (AI 서버) |
| 00:10 | 오늘의 퀴즈 생성, 배정 (AI 서버) |
| 00:20 | 예적금 정산 (건별 트랜잭션, 실패 건은 다음 날 재처리) |
| 09:00 | 하루 시작 알림 (오늘의 퀴즈, 뉴스) |
| 19:00 | 적금 납입 리마인더 |

## 인증

- JWT access token(30분) + refresh token(14일)
- refresh token은 해시로 DB(`refresh_tokens`) 저장
- 재발급 시 기존 토큰 폐기 후 신규 발급 (회전)

## 가족과 자산 규칙

- 가족 초대 코드
  - 6자리, 유효 시간 10분, 전역 UNIQUE
  - 재발급 시 기존 코드 삭제 → 가족당 유효 코드 1개 유지
- 잔여 자산 보호
  - 자산(포인트, 예적금, 투자)이 남은 자녀는 탈퇴, 가족 해체, 가족 제외 불가
  - 소속 상실 시 자산 처분 경로가 사라지는 교착 방지
- 가족 해체는 소프트 삭제, 거래, 자산 이력 보존

## 알림

- FCM 푸시 발송
- 디바이스 토큰 전역 UNIQUE → 기기에서 계정 전환 시 기존 행을 새 사용자로 갱신(upsert)
