# Idea

## 프로젝트 개요

- 프로젝트명: 도토리
- 한 줄 소개: 부모가 만든 안전한 가정 내 경제 시스템에서, 아이가 도토리 포인트를 벌고·모으고·쓰고·투자하며 금융 개념을 경험하는 서비스
- 배경 / 문제의식: 초등학생은 돈을 직접 벌고 저축·소비하는 경험이 적어 금융 개념을 설명으로만 접한다. 부모는 용돈과 보상을 통해 경제 습관을 가르치고 싶지만, 일관된 기준을 세우기 어렵다.

## 핵심 가치

- 경험형 금융교육 — 설명이 아닌 소득→저축→소비→투자 흐름을 직접 경험
- 가족 맞춤형 경제 — 부모가 집안일 보상, 예·적금, 상점 가격을 직접 정의
- 안전한 통제 — 부모 승인과 가족 단위 환경 안에서만 금융 활동 수행
- 지속 동기 — 다람쥐·도토리 세계관, 성장과 보상으로 참여 유지

## 타겟 사용자

- 부모: 자녀의 경제 습관을 지도하고 싶은 보호자. 보상·이자·상점 가격을 직접 설정하고, 자녀 활동과 승인 요청을 확인
- 아이 (초등 4~6학년): 금융 경험이 부족하고 미션·보상에 익숙함. 행동 결과를 포인트 변화로 경험

## 주요 기능 목록

| 기능         | 설명                                                                    |
| ------------ | ----------------------------------------------------------------------- |
| 인증/인가    | 회원가입, 로그인, 아이디/비밀번호 찾기, 이메일 인증 (Parent/Child 공통) |
| 가족         | 가족 생성·조회·탈퇴, 자녀 관리                                          |
| 초대         | 부모-아이 계정 연결 (사용자 검색, 초대 생성/수락/거절/취소)             |
| 계좌         | 실 계좌 연동·조회, 거래 내역 조회                                       |
| 지갑         | 포인트 충전·지급·정기지급, 잔액 및 거래내역 조회                        |
| 예적금       | 부모 설정형 예·적금 상품 가입, 손익 조회, 중도해지·만기수령             |
| 투자         | 모의투자 상품 매수/매도, 보유자산·거래이력 조회                         |
| 투자/뉴스    | AI가 생성한 가상 뉴스 기반 투자 상품 가격 변동                          |
| 소비(상점)   | 부모 설정형 상품 등록, 아이 구매(1일 1회 제한)                          |
| 소득(집안일) | 할 일 등록·완료요청·승인, 완료 시 포인트 보상                           |
| 퀴즈         | 단어장 기반 AI 생성 퀴즈, 정답 시 포인트 보상                           |
| 단어장       | 경제/금융 용어 학습 콘텐츠, 퀴즈 소스로 활용                            |
| 리포트/통계  | 부모용 자녀 경제활동 요약, 수입/소비 통계, 자산 현황                    |
| 마이페이지   | 회원정보 수정, 비밀번호 변경, 회원 탈퇴                                 |
| 알림         | 승인 요청, 거래 발생, 보상 지급 등 이벤트 알림                          |
| 보류         | 다자녀 관리, 상세 설정, AI 가격 자동 갱신 시스템                        |
