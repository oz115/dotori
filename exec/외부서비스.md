# 외부 서비스

[← 포팅 매뉴얼로 돌아가기](포팅메뉴얼.md)

| 서비스 | 용도 | 설정 | 발급 방법 |
| --- | --- | --- | --- |
| **Gmail SMTP** | 이메일 인증 코드 발송 (회원가입, 아이디 찾기) | `smtp.gmail.com:587`, STARTTLS, 타임아웃 5초 | Google 계정 > 보안 > 2단계 인증 활성화 > 앱 비밀번호 생성 → `MAIL_USERNAME`(주소), `MAIL_PASSWORD`(앱 비밀번호) |
| **SSAFY 가상 금융망 API** | 계좌 연동, 현금↔도토리 충전·환전 | `https://finopenapi.ssafy.io/ssafy/api/v1`, 기관코드 `00100`, 핀테크 앱 번호 `001` | SSAFY 금융망 포털에서 API 키 발급 → `FINANCE_API_KEY` |
| **SSAFY GMS** | AI 서버의 LLM 호출 (투자 뉴스 생성, 상점 가격·할 일 보상 책정, 금융 퀴즈) | `https://gms.ssafy.io/gmsapi` (OpenAI 호환), `gpt-4o-mini`, 퀴즈 `gpt-5.4-mini` | SSAFY GMS에서 키 발급 → `GMS_KEY` |
| **AWS S3** | 할 일 인증 사진 저장 | 버킷 `s15p21a505dotori`(비공개), `ap-northeast-2`, presigned URL 유효 600초 | IAM 사용자에 해당 버킷 `s3:PutObject`(업로드)·`s3:GetObject`(presigned 조회) 권한 부여 → Access Key 발급 |
| **AWS ECR** | 백엔드·AI 서버 Docker 이미지 저장소 | `dotori-backend`, `dotori-ai` | IAM 사용자에 ECR push/pull 권한 부여 → Jenkins Credentials 와 `vault_ecr_*` |
| **Firebase Cloud Messaging** | 푸시 알림 | 서버: Admin SDK 서비스 계정 키 / 앱: `google-services.json` (패키지 `com.bana.dotori`) | Firebase 콘솔 > 프로젝트 설정 > 서비스 계정 > 새 비공개 키 / Android 앱 등록 후 `google-services.json` 다운로드 |
| **Let's Encrypt** | HTTPS 인증서 | webroot 방식, 자동 갱신 | playbook이 `domain_name`, `certbot_email` 로 자동 발급 |
