# 시연 시나리오

[← 포팅 매뉴얼로 돌아가기](포팅메뉴얼.md)

아이가 갖고 싶은 자전거를 사기 위해 투자·저축·퀴즈·미션으로 도토리를 모으고, 부모가 부족한 만큼
도토리를 보태 주어 결국 자전거를 구매하는 흐름입니다. 부모와 자녀 기기 두 대로 진행합니다.

| 단계 | 기능 | 진행 기기 |
| --- | --- | --- |
| 0 | 상품 등록 · 저금 목표 확인 | 부모 → 자녀 |
| 1 | 주식 투자 (매수) | 자녀 |
| 2 | 저축 (만기 · 해지) | 자녀 |
| 3 | 퀴즈 | 자녀 |
| 4 | 미션 인증 · 승인 | 자녀 → 부모 |
| — | *하루 경과* | |
| 5 | 주식 매도 | 자녀 |
| 6 | 도토리 주기 | 부모 → 자녀 |
| 7 | 메인 화면 (목표 달성 확인) | 자녀 |
| 8 | 상점 구매 | 자녀 |

<br>

## 0. 상품 등록

**부모** — 상점에 자전거를 등록

> "어 그러면 도토리 상점에 자전거 등록해줄게!"

**자녀** — 메인 화면의 **'조금만 더 모으면'** 에서 자전거까지 몇 포인트 남지 않은 것을 확인

> 1. "아빠~! 자전거 사고 싶어."
> 2. "오 몇 포인트 안 남았잖아?"
> 3. "도토리를 모아야 할텐데??"

## 1. 주식 투자

**자녀** — 오늘의 뉴스를 하나 확인하고, 오를 것 같은 기업 하나를 골라 매수

> 1. "오늘의 뉴스나 확인해볼까?"
> 2. "이거 오를 거 같은데? 이거 사야쥥~"
> 3. "아 맞다 오늘 저축한 거 끝나는데??"

## 2. 저축

**자녀** — 오늘이 예금 만기일인 상황

- 예금: 만기 처리
- 자유입출금: 해지

> 1. "아싸! 저축한거 가져가야지~"
> 2. "음 아직도 모자르네?"
> 3. "아 맞다 퀴즈도 풀면 도토리가 나오잖아?"

## 3. 퀴즈

**자녀** — 오늘의 퀴즈 풀기

- 1번째 시도: 오답 → 초성 힌트 획득
- 2번째 시도: 정답

> 1. "음 이거 아닌가?"
> 2. "오 힌트 개꿀 ㅋㅋ"
> 3. "맞췄다!!! 헤헤"

## 4. 미션

**자녀** — '수학문제집 풀기' 미션을 확인하고, "다 풀었어요!" 내용과 인증샷을 첨부해 제출

> 1. "도토리가 조금 더 필요해"
> 2. "오늘 숙제 끝냈다고 검사 맡아야지."
> 3. "아빠 승인 해주세요."

**부모** — 인증 요청을 확인하고 한번 훑어본 뒤 승인

> "어 잘 풀었네~"

## *하루 경과*

## 5. 주식 매도

*(나레이션) "다음 날.."*

**자녀** — 전날 매수한 기업의 주가가 오른 것을 확인하고 매도

> 1. "아~ 얼마가 올랐지?"
> 2. "오 많이 올랐네? 팔아야지!!"

## 6. 도토리 주기

**자녀** — 도토리가 아직 모자라 아쉬운 상황

> 1. "아직도 도토리가 모자라네..? 아쉽다…"

**부모** — 부족한 도토리만큼 자녀에게 지급

> "우리 아이가 열심히 했으니까 도토리 더 줘야겠다"

## 7. 메인 화면

**자녀** — '조금만 더 모으면' 에서 자전거를 구매할 도토리가 채워진 것을 확인

> 1. "우와! 자전거 살 수 있겠다!"

## 8. 상점 (상품 상세)

**자녀** — 등록된 자전거 상품을 구매하고 구매 내역 확인

> 1. "아빠 감사해요 히히히"
