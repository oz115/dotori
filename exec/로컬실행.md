# 로컬 실행

[← README로 돌아가기](../ReadMe.md)

모든 명령은 저장소 루트에서 시작합니다.

## 사전 요구 사항

- Node.js 및 npm
- JDK 21
- Python 3.11 (AI 서버를 함께 띄울 때)
- Docker Engine 및 Docker Compose

## 1. PostgreSQL, Redis, RabbitMQ 실행

```bash
docker compose -f docker-compose.local.yml up -d
```

## 2. Backend 실행

```bash
cd backend
./gradlew bootRun
```

Windows에서는 다음 명령을 사용할 수 있습니다.

```powershell
cd backend
.\gradlew.bat bootRun
```

## 3. Frontend 실행

```bash
cd frontend
npm ci
npm start
```

## 4. AI 서버 실행 (선택)

AI 서버 없이도 백엔드와 앱은 동작하지만, 뉴스, 퀴즈 생성과 상점 가격, 할 일 보상 책정은 AI 서버가 있어야 채워집니다.

```bash
cd AI
python -m venv .venv
source .venv/bin/activate        # Windows: .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
fastapi dev app/main.py
```

자세한 내용은 [`AI/README.md`](../AI/README.md)를 참고합니다.

환경변수는 루트와 `frontend/`의 `.env.example`을 참고해 별도의 `.env` 파일에 작성합니다. 비밀값은 저장소에 커밋하지 않습니다. 전체 변수 목록은 [`환경변수.md`](환경변수.md)에 있습니다.

> 운영 서버 배포(EC2, Jenkins, Ansible)는 [포팅 매뉴얼](포팅메뉴얼.md)을 참고합니다.
