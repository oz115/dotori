# 환경 변수

[← 포팅 매뉴얼로 돌아가기](포팅메뉴얼.md)

값은 두 가지 방식으로 주입됩니다.

- **운영(EC2)**: `dotori-ansible` 의 `group_vars/all.yml`(설정값)과 `group_vars/vault.yml`(비밀값, ansible-vault 암호화)
  → `docker-compose.yml` 의 `environment` 로 각 컨테이너에 주입합니다.
- **로컬**: 루트 `.env`(Spring), `AI/.env`(AI 서버), `frontend/.env`(앱). 각 폴더의 `.env.example` 을 복사해서 씁니다.
  Spring은 `optional:file:.env`, `optional:file:../.env` 를 설정으로 import하며, OS 환경 변수가 항상 우선합니다.

## 4. 배포 설정 (`dotori-ansible`)

| 파일 | 만드는 방법 | 내용 |
| --- | --- | --- |
| `inventory/hosts.ini` | `hosts.ini.example` 복사 | EC2 퍼블릭 IP, `ansible_user=ubuntu`, pem 경로 |
| `group_vars/all.yml` | `all.yml.example` 복사 | 아래 표 |
| `group_vars/vault.yml` | `vault.yml.example` 복사 후 `ansible-vault encrypt` | 비밀값 |

`all.yml` 에서 환경에 맞게 채우는 값:

| 변수 | 운영 값 | 설명 |
| --- | --- | --- |
| `app_dir` | `/opt/dotori` | 서버의 compose 디렉토리 |
| `aws_account_id` | `<AWS 계정 ID>` | ECR 레지스트리 주소 |
| `aws_region` | `ap-northeast-2` | |
| `image_tag` / `ai_image_tag` | `latest` | 롤백 시 커밋 해시 태그 |
| `enable_ai` | `true` | ECR에 `dotori-ai` 이미지가 없으면 `false` ([배포 특이사항](포팅메뉴얼.md#8-배포-특이사항) 참고) |
| `domain_name` | `j15a505.p.ssafy.io` | 채우면 HTTPS 자동 적용 |
| `certbot_email` | `<인증서 만료 알림 이메일>` | |
| `fcm_credentials_src` | `<로컬의 Firebase 키 파일 경로>` | |
| `mail_host` / `mail_port` | `smtp.gmail.com` / `587` | |
| `jenkins_port` | `9090` | |

`vault.yml` 에 채우는 값(모두 `<...>`):

```yaml
vault_postgres_password: ""
vault_redis_password: ""
vault_rabbitmq_password: ""
vault_jwt_secret: ""
vault_finance_api_key: ""
vault_ecr_access_key_id: ""       # ECR pull용 IAM
vault_ecr_secret_access_key: ""
smtp_mail_username: ""            # Gmail 주소
smtp_mail_password: ""            # Gmail 앱 비밀번호
aws_access_key_id: ""             # S3용 IAM (vault_ 접두사 없음)
aws_secret_access_key: ""
vault_internal_token: ""          # openssl rand -hex 32
vault_gms_key: ""                 # SSAFY GMS API 키
```
